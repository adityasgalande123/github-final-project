# Simple Interest Calculator

A simple Bash script that calculates simple interest based on user-provided input.

## Description

This project contains a command-line calculator that computes **simple interest**
using the standard formula:

```
Simple Interest (SI) = (Principal x Rate x Time) / 100
```

## Input Fields

The script prompts the user for three values:

1. **Principal** – the initial amount of money (P)
2. **Rate of Interest** – the annual interest rate, in percent (R)
3. **Time Period** – the duration in years (T)

## Output

The script calculates and displays the simple interest based on the values entered,
along with the total amount (Principal + Interest).

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

You will be prompted to enter the principal amount, rate of interest, and time period.
The script will then display the calculated simple interest and total amount.

## Example

```
Enter Principal Amount: 1000
Enter Rate of Interest (%): 5
Enter Time Period (years): 2

Simple Interest: 100
Total Amount: 1100
```
